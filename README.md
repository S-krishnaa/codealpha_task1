📸 CodeAlpha Task 1 — Image Gallery
This is a responsive image gallery project created as part of the CodeAlpha Frontend Development Internship. It showcases HTML, CSS, and JavaScript skills through a dynamic gallery layout with navigation and visual effects.
✨ Features
- Grid-based image layout using HTML & CSS
- JavaScript-powered navigation:
- Next/Previous buttons
- Lightbox view for enlarged images
- Hover effects and smooth transitions
- Responsive design for mobile, tablet, and desktop
- Bonus: Image filters/categories (if implemented)
🚀 Technologies Used
- HTML5
- CSS3 (Flexbox/Grid, Transitions)
- JavaScript (DOM manipulation, Event handling)
